# Supplementary Material

**From Operator Rationales to Dispatch Policy: LLM-Enabled Semantic Reward Learning for V2G Scheduling**

Zeyu Liang, Tao Qian, Qinran Hu, and Zaijun Wu, School of Electrical Engineering, Southeast University, Nanjing, China.

This repository contains the supplementary material of the paper. The complete document is
[`Supplementary_Material.pdf`](Supplementary_Material.pdf); the folder [`sources/`](sources) holds the same content as
separate text, data, and image files.

| Part | Content | Source files |
|---|---|---|
| S1 | PPO observation and action vectors | `observation_vector.md` |
| S2 | LLM annotation prompt | `prompt_template_v6.md` |
| S3 | Label-validation checks of the annotation pipeline | `validation_stages.md` |
| S4 | Table III with standard deviations across seeds | `table3_seed_sd.md`, `table3_seed_sd.csv` |
| S5 | Reward-model results on the common day split | `rm_held_out_results.md` |
| S6 | Language-interface study: the 52 operator texts and outcomes | `language_interface_texts.md` |
| S7 | Fig. S1: battery-degradation retraining | `battery_degradation.md`, `figS1_battery_degradation.png` |
| S8 | Table S1: daily network-loss energy | `network_loss.md`, `network_loss.csv` |
| S9 | Experimental settings | `settings.json` |
